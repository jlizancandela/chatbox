Especificaciones Técnicas del Componente Launcher (Floating Widget)

1. Posicionamiento Fijo

Anclaje fixed bottom-6 right-6 con z-index 50 para flotar sobre canvas sin colisionar con sticky headers ni tooltips. Margen de seguridad 24px en desktop.

2. Accesibilidad & Ergonomía

Touch Target de 56×56px (superior al umbral WCAG de 44px). Compatible con lectura de pantalla mediante aria-expanded y foco con teclado (Esc / Tab).

3. Lógica Proactiva de Teaser

Disparador tras 8s de inactividad o scroll > 40%. Persiste dismiss en sessionStorage para no repetir interrupciones en la misma sesión.
