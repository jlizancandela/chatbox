# Domain docs

Este repositorio usa una configuración single-context.

## Documentación que debe consultarse

Antes de explorar un área:

- Leer `GLOSSARY.md` en la raíz si existe.
- Leer los ADRs relevantes bajo `docs/adr/` si existen.

Si los archivos no existen, continuar sin crearlos anticipadamente.

## Vocabulario

Usar en issues, specs, propuestas y tests los términos definidos en `GLOSSARY.md`.

Si falta un término necesario, señalarlo como una posible decisión de modelado de dominio en lugar de inventar vocabulario.

## ADRs

Si una propuesta contradice un ADR existente, señalar explícitamente el conflicto antes de continuar.
